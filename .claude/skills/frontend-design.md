# Frontend Design Guide

This guide provides direction for creating distinctive, intentional visual design for responsive web UIs, app interfaces, dashboards, websites, and viewport-adaptive components. The core philosophy positions you as an aesthetic leader who rejects templated defaults in favor of subject-specific choices.

## Before You Design

Identify one concrete subject, its audience, and the page's single job. Study the subject's own world — its materials, instruments, artifacts, and vernacular — to find distinctive choices rather than applying generic templates.

## Key Principles

**Ground in subject matter**: Every design decision should flow from the actual content and its context. The brief's vernacular should inform color, type, layout, and motion.

**Typography as personality**: Pair display and body faces deliberately — not the same families you would reach for on any other project. Type should feel native to the subject.

**Structure encodes meaning**: Structural devices — numbering, eyebrows, dividers, labels — should encode something true about the content, not merely decorate it. Numbered markers (01 / 02 / 03) only work when the content actually follows a meaningful sequence.

**Deliberate motion**: Animation should serve the subject strategically. Scattered effects throughout a page make designs feel AI-generated. Orchestrated moments — one or two signature transitions — land with more impact.

**Writing standards**: Copy serves understanding and usability. Use active voice ("Save changes" not "Submit"), be specific rather than clever, and maintain consistent vocabulary throughout user flows.

## Process

**Pass 1 — Brainstorm**: Propose a design plan that covers:
- Color palette (grounded in the subject, not trend)
- Type pairing (display + body, with rationale)
- Layout structure (what it encodes about the content)
- Signature motion or interaction moment
- Any unconventional element specific to this brief

**Pass 2 — Critique**: Before building, review the plan against the brief:
- Would these choices work for any similar project, or are they truly specific to this one?
- Does each structural device encode something real?
- Is motion purposeful or scattered?
- Does the copy use the brief's own language?

## Avoiding Generic Defaults

Three common AI-generated aesthetics to actively sidestep:
1. Cream/off-white backgrounds paired with serif headlines and terracotta/rust accent colors
2. Near-black backgrounds with acid green, electric blue, or neon accent colors
3. Newspaper-style dense grid layouts with heavy column rules

The test: if your design could plausibly appear on a dozen unrelated sites in the same category, it is not specific enough.

## Scope

Use this skill for: responsive web UIs, app interfaces, dashboards, websites, wireframes, and viewport-adaptive components.

Do NOT use this skill for: fixed-canvas design (posters, flyers, slides, social graphics) — use the `visual-design` skill for those.
